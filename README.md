## Featured project — [acrars](https://github.com/Youssef-salem/acrars)

An accessibility-focused fork of [RARS](https://github.com/TheThirdOne/rars), the RISC-V Assembler and Runtime Simulator.

* Screen-reader friendly editor for VoiceOver (macOS), NVDA / JAWS / Narrator (Windows)
* Native macOS & Windows file pickers and menu bar
* Full keyboard navigation (Ctrl+Tab focus escape, Cmd+1–9 to switch open files, Window menu listing every open tab)
* Accessible names, descriptions and mnemonics on every UI element, tool window and dialog
* Ships as a self-contained `RARS.app` (macOS), `RARS.msi` (Windows) and `RARS.deb` (Linux) — no separate Java install needed
