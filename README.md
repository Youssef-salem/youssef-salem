## Featured project — [acrars](https://github.com/Youssef-salem/acrars)

A fork of [RARS](https://github.com/TheThirdOne/rars), the RISC‑V Assembler
and Runtime Simulator. I started it because I kept hitting friction using
RARS as a student myself — clunky packaging, no native OS integration,
awkward keyboard handling — so I rewrote those pieces end‑to‑end and
shipped it as a real installable app on every major platform.

**What's in it**

* **Native installable apps** — self‑contained `RARS.app` (macOS),
  `RARS.msi` (Windows) and `RARS.deb` (Linux). Users don't need to install
  Java separately.
* **Native OS integration** — real macOS / Windows file pickers, proper
  macOS screen menu bar, native About / Preferences hooks.
* **Full keyboard navigation** — `Ctrl+Tab` to escape focus from the editor,
  `Cmd+1–9` to jump between open files, a Window menu listing every open tab,
  mnemonics on dialogs.
* **Screen‑reader support** — works with VoiceOver (macOS), NVDA, JAWS and
  Narrator (Windows). Every UI element, dialog and tool window has an
  accessible name and description.
* **Automated multi‑OS releases** — a GitHub Actions pipeline builds the
  macOS, Windows, Linux and `.jar` artifacts on every tagged commit.

**Stack:** Java 17 (Swing), `jpackage`, WiX (MSI), GitHub Actions.
